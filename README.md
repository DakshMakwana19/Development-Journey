# 🚀 Development Journey

A collection of web development projects showcasing my learning and experimentation journey.

## 📂 Projects

### 🌍 WanderVista — 3D Tourism Website
> **Root files:** `index.html`, `styles.css`, `script.js`, `images/`

A stunning 3D tourism website with immersive animations, interactive destination cards, and modern glassmorphic design.

- **Tech:** HTML, CSS, JavaScript
- **Features:** 3D transforms, parallax effects, destination explorer, booking forms

---

### 🧠 AI/ML Learning Tracker
> **Directory:** `aiml-tracker/`

A gamified AI/ML learning platform with XP systems, DSA tracker, roadmaps, and achievement badges — designed to make studying addictive.

- **Tech:** Next.js, TypeScript, Tailwind CSS, Zustand
- **Features:** Dashboard, DSA problem tracker, learning roadmap, analytics, gamification

---

### 🌙 Chrome Ambient Theme — New Tab Extension
> **Directory:** `chrome-ambient-theme/`

A premium dark-mode Chrome New Tab extension with ambient glowing orbs, fluid animations, and glassmorphic UI.

- **Tech:** HTML, CSS, JavaScript (Chrome Extension API)
- **Features:** Multiple dark themes (Aurora, Neon, Ember, Void, Emerald), animated backgrounds, quick links

---

### 🎨 Chrome Dark Skin
> **Directory:** `chrome-dark-skin/`

A sleek dark skin theme for Chrome browser.

- **Tech:** Chrome Theme API

---

### 🎵 Spotify Starry Night Setup
> **File:** `spotify-starrynight.ps1`

PowerShell script to install and configure the Starry Night theme for Spicetify (Spotify customization tool).

---

## 🛠️ Setup

Each project can be run independently:

- **WanderVista:** Open `index.html` in a browser
- **AI/ML Tracker:** `cd aiml-tracker && npm install && npm run dev`
- **Chrome Extensions:** Load unpacked from `chrome://extensions`
